# Home Page

## Purpose

Introduce Kalana, prove the quality and range of the work, and create a memorable emotional impression without placing the whole portfolio on one page.

## Section 1: Signature hero

**Content**

- Kalana Didulanga
- Suggested headline: `I build software for the real world.`
- One short supporting line covering web, mobile, desktop, and operational systems
- Primary action: Explore work
- Secondary action: About Kalana
- Availability or current-role detail only if accurate and maintained

**Concept**

Left-aligned identity and copy occupy roughly five columns. The Living Systems Atlas occupies the remaining space and may extend beyond the fold. A fine connection from the Atlas continues into Selected Work, creating the first section handoff.

**Assets**

- KD monogram and wordmark, SVG
- Living Systems Atlas master artwork, SVG or Canvas scene
- six domain glyphs, SVG
- optional subtle portrait fragment for large screens, real photo only
- social preview image

**Motion**

- headline resolves line by line
- Atlas nodes wake in sequence after the main copy is visible
- pointer proximity gently bends or illuminates nearby paths
- scroll compresses the Atlas and passes one active path into the next section

## Section 2: Selected systems

**Content**

Feature three to five strong systems, with different emphasis for Uniguru Operations Platform, Kendara, Hotel Management System, and other owner-approved flagship projects.

**Concept**

Avoid three matching cards. Use one wide anchor project, two compact text-led project signals, and a live path to the Work explorer. A project can be represented by title, outcome, role, platform, and one meaningful visual detail.

**Assets per featured project**

- approved real screenshot or no screenshot
- one crop or UI detail if privacy allows
- one accurate architecture or workflow diagram for deep case studies
- project mark or category glyph
- Open Graph image for the detail page

**Motion**

The project title sharpens before metadata. Hovering or focusing lights the shared Atlas path. A screenshot, when available, reveals through a controlled mask rather than floating as a generic browser card.

## Section 3: How I think

**Content**

Four principles grounded in the work:

- understand the operation
- make complexity legible
- build for reliability
- refine the last interaction

Each principle must link to one real project decision.

**Concept**

A single continuous schematic changes state as each principle enters. This replaces a four-card feature grid.

**Assets**

- one modular technical-field diagram, SVG
- four small state illustrations derived from the same diagram
- optional handwritten annotation texture from Kalana

## Section 4: Range

**Content**

Web platforms, mobile apps, Windows software, commerce and POS, and technical leadership. Show the breadth without presenting ten separate services.

**Concept**

A horizontal-to-vertical responsive field map. Each discipline sits at a coordinate and exposes relevant projects on interaction. The atmosphere gradually becomes lighter toward the About preview.

**Assets**

- five discipline glyphs
- small truthful platform symbols from the chosen icon family
- relationship data from project configuration

## Section 5: Lab signal

**Content**

Two or three real or planned experiments and a link to Lab.

**Concept**

The structured system field briefly becomes playful. Pixels, cursor trails, or a small interactive sandbox appear without changing the green identity.

**Assets**

- one interactive experiment preview
- two poster frames for fallback and social sharing
- pixel or particle texture sheet

## Section 6: Personal note

**Content**

A short first-person statement about building, leading developers, and learning across platforms. Link to About.

**Concept**

Use an asymmetric portrait crop and a workspace detail, blended into the same page field with soft shadows and no card boundary.

**Assets**

- primary portrait, vertical
- secondary candid portrait or hands-at-work detail
- real workspace photograph
- signature or handwritten mark, optional

## Section 7: Closing invitation

**Content**

Suggested heading: `Have a system worth building?`

Provide one contact action and direct email access. Do not repeat multiple CTAs with the same intent.

**Concept**

The connected lines from the entire page converge into one quiet green source. The footer grows naturally out of the same field with no hard boundary.

**Assets**

- no new hero artwork
- a compact KD mark
- social icons from one icon family
