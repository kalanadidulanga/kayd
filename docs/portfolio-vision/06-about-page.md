# About Page

## Purpose

Show the human behind the systems, make career facts easy to verify, and express how Kalana thinks without turning the page into a résumé dump.

## Section 1: Personal opening

Use Kalana's name, current truthful positioning, one concise first-person paragraph, and a strong natural portrait. The portrait should feel observed rather than staged.

**Assets:** primary portrait, alternative mobile crop, monochrome fallback, accessible alt text.

## Section 2: The path

Present TwinCoreTech, C-Lento, freelance work, Fuchsius, and Techseya from the existing work-history data. Use a continuous vertical path with expandable chapters. Current roles receive stronger contrast, not novelty badges.

**Assets:** verified company logos where permitted, one shared timeline-path graphic, optional real workplace details.

## Section 3: How I work

Cover discovery, architecture, collaboration, implementation, and refinement. Each stage should cite a real example from a project. Use one evolving workspace diagram rather than five cards.

**Assets:** desk notes, wireframes, architecture sketch, code or terminal crop with sensitive data removed, review annotation.

## Section 4: Across platforms

Explain the relationship between web, mobile, Windows, APIs, and leadership. This is a narrative map, not a long skill-chip wall. Link each area to relevant Work filters.

**Assets:** platform relationship diagram and restrained icons from one family.

## Section 5: Beyond client work

Introduce experiments, tools, learning interests, and personal curiosity. Link to Lab and Notes. Include only interests Kalana confirms.

**Assets:** real notebook or workspace image, Lab preview, optional personal object photograph.

## Section 6: Résumé and contact

Provide View résumé, Download PDF, and Contact as distinct actions. The PDF must match the site's visual identity but prioritize print readability.

## Photography direction

- natural window light or soft directional studio light
- green-black or neutral environment, not a saturated green wash
- real desk and equipment
- quiet expression and candid working posture
- subtle grain and realistic skin tones
- avoid crossed-arm corporate portraits, fake offices, and AI-generated portraits presented as real

## Motion

- portrait enters through a slow crop reveal
- career path draws as entries become readable
- workspace fragments align into the process diagram
- no looping animation near long text
