# Kalana Portfolio Vision

**Status:** design source of truth  
**Date:** 2026-10-20  
**Scope:** complete creative, content, motion, and asset specification for the next portfolio redesign

This folder turns the portfolio research into an implementation-ready system. It preserves Kalana's preferred green identity while replacing the current component-demo feeling with one continuous, immersive personal world.

## Design read

A developer portfolio for potential clients, recruiters, and creative developers, using an immersive, personal, engineering-led visual language. The aesthetic is a deep botanical digital environment with editorial clarity and precise software-system details.

| Dial | Value | Meaning |
| --- | ---: | --- |
| Design variance | 8/10 | Each page has its own composition, but shares one world |
| Motion intensity | 7/10 | Smooth, responsive, and atmospheric without constant spectacle |
| Visual density | 4/10 | Rich enough to explore, clear enough to scan |

## Core decision

Green is not an optional accent picker. It is the identity. The site uses a controlled family of mineral, moss, mint, and deep forest greens. Neutral ink and mist colors give the green room to breathe.

Sections should not look like stacked rectangles. A visitor should feel movement through one continuous environment. Section changes are expressed through light, shadow, texture, composition, and motion rather than alternating hard background bands.

## Binding principles

- Real work comes first. Decoration cannot pretend to be product evidence.
- Personal details come from Kalana's actual work, process, desk, notes, and engineering decisions.
- All project counts, roles, technologies, dates, and outcomes come from repository data or owner-approved copy.
- One green color family carries the whole experience.
- Every animation must explain hierarchy, state, relationship, or feedback.
- Reduced motion exposes the complete static composition.
- No fake product screenshots, fake client metrics, or invented testimonials.
- The site must remain useful on mobile, keyboard accessible, and readable without animation.
