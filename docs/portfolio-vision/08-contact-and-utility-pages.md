# Contact and Utility Pages

## Contact page

### Opening

Suggested heading: `Tell me what needs to work better.`

Follow with a short line inviting a product idea, operational problem, engineering role, collaboration, or hello.

### Form

Fields:

- name
- email
- message
- optional intent: project, role, collaboration, question

The form needs visible labels, inline validation, pending state, success state, error recovery, spam protection, and a privacy note. Provide direct email and LinkedIn as alternatives.

### Concept

The page is a quiet clearing in the same dark environment. A concentrated green light sits behind the form area. As fields become valid, one subtle connection path completes. The effect must not imply submission before the form actually succeeds.

### Assets

- compact KD mark
- one abstract connection field, SVG or CSS
- success-state line animation
- social icons from the standard icon family

## Résumé page

- concise profile summary
- current and past roles from repository data
- selected work
- core capabilities with proof links
- education and contributions when verified
- view and download actions
- printer-friendly layout and tagged accessible PDF

**Assets:** PDF template, KD mark, small QR code only if it leads to the canonical portfolio URL.

## Uses page, optional

Show real hardware, software, development setup, and working preferences only after Kalana supplies the details and photography. Interactive annotations can reveal why each tool is useful.

## Now page, optional

A short, owner-maintained view of current professional focus, experiments, and learning. Do not publish it unless it can be kept current.

## Error and empty states

- 404: a disconnected Atlas node with routes back to Work, Lab, and Home
- no Work results: show filter-reset action and related categories
- no Notes results: suggest topics or clear search
- form error: preserve all entered data and explain the next action

## Footer

The footer is part of the final scene, not a separate dark rectangle. Include navigation, email, selected social links, copyright year, and a short personal line. Do not include build versions, weather, fake availability, or decorative status indicators.
