# AI Asset Generation Prompts

## Purpose

These prompts keep generated supporting artwork inside the same world. Use them with an image model for concept art, textures, and poster frames. Do not use image generation for real portraits, product screenshots, client logos, or evidence of completed work.

## Shared style block

Append this block to every prompt:

> Art direction for Kalana Didulanga's personal software engineering portfolio. Deep forest-black canvas, mineral green surfaces, controlled signal-mint light, pale mist highlights, fine technical linework, subtle organic field patterns, precise editorial composition, quiet cinematic depth, realistic material response, restrained bloom, gentle grain, high contrast focal hierarchy. Personal, curious, engineered, and calm. No purple, blue neon, orange accent, generic SaaS gradient, generic glass cards, fake browser UI, fake code, random text, logos, watermarks, cyberpunk city, literal jungle leaves, or stock-photo look.

## Prompt 1: Living Systems Atlas

> Create an abstract living systems atlas for a full-stack software engineer. A network of six distinct domains grows from one core: web platforms, mobile applications, Windows software, business operations, commerce systems, and creative experiments. Combine accurate node-link logic with subtle root and topographic forms. Leave intentional negative space on the left for large portfolio typography. Wide 16:10 composition. The system should feel usable as a layered SVG or Canvas reference, with clear foreground, middle, and background paths. [Shared style block]

**Generate:** master wide image, isolated node layer, isolated path layer, depth mask, mobile vertical composition.

## Prompt 2: Technical field-note background

> Create a seamless, low-contrast technical field-note texture combining fine contour lines, sparse coordinate marks, and modular system paths. It must support readable body text and disappear naturally at the edges. No readable words or numbers. [Shared style block]

**Generate:** 2048 square tile, dark and light variants.

## Prompt 3: Operations-system case-study artwork

> Create an abstract editorial illustration of a complex operations platform. Show leads, staff roles, documents, deadlines, permissions, and scheduled processes as a clear connected system. Emphasize orchestration and reliability. Do not imitate a software screenshot and do not include text. Wide 8:5 composition with space for case-study metadata. [Shared style block]

## Prompt 4: Hospitality-system artwork

> Create an abstract systems illustration for hotel operations. Connect reservations, front desk, rooms, restaurant, inventory, staff, and accounting through one coherent operational flow. Use spatial layers and precise paths, not icons floating in cards. No text or fake dashboard. [Shared style block]

## Prompt 5: Kendara contextual artwork

> Create a respectful abstract visual for a Sri Lankan astrology software project. Combine circular astronomical geometry, time calculation, location, multilingual interpretation, and a subtle reference to traditional chart structure. Keep it technical and contemporary. Avoid mystical clichés, zodiac stock imagery, religious symbols, and fake interface text. [Shared style block]

## Prompt 6: Lab poster system

> Create an experimental poster for a creative coding lab inside a green software-engineering portfolio. Use pixel clusters, particle routing, cursor-field traces, and one surprising spatial distortion. The poster must feel playful but belong to the same deep green brand world. No words or fake UI. 4:3 composition. [Shared style block]

## Prompt 7: Contact clearing

> Create a minimal abstract background in which many fine system paths converge into one calm source of mint light. Large quiet central area for an accessible contact form. The composition should feel like arriving at a clearing after moving through a connected digital environment. No text, cards, buttons, or interface elements. Vertical 4:5 composition. [Shared style block]

## Prompt 8: 404 disconnected node

> Create a small isolated technical illustration of one disconnected node searching for its network. It should feel thoughtful and lightly playful rather than broken or alarming. Transparent background, simple silhouette, readable at 320 pixels. [Shared style block]

## Review checklist for every generated asset

- Is the green family consistent with the tokens?
- Does it have one clear focal idea?
- Can text remain readable near it?
- Does it avoid fake product evidence?
- Does it avoid unrelated purple, cyan, or orange accents?
- Does it avoid generic AI mesh and glass-card styling?
- Can it be cropped for desktop and mobile?
- Does it still look intentional with reduced motion?
- Does it add meaning to the section?

Reject and regenerate if any answer is no.
